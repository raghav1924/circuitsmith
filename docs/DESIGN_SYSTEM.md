# CircuitSmith Design System

CircuitSmith integrates 5 core patterns from `DESIGN_INSPIRATION.md`:

1. **#12 Bento Grid:** Asymmetric card layout organizing simulation canvas, state machine, linter, and code generation.
2. **#20 Cyberpunk / Dark Mode:** `#07090e` base, vibrant `#f43f5e` rose, emerald `#10b981`, and cyan `#00f0ff`.
3. **#10 Glassmorphism:** Translucent card backdrops with `rgba(255, 255, 255, 0.08)` borders.
4. **#3 Swiss Typography:** Monospaced data displays, clear contrasts, and balanced spacing.
5. **#24 Cybercore Visual Studio:** Real-time state machine animations and multi-node cascading failure topology.
